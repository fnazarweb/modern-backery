# Modern Bakery — Landing Page

A responsive bakery landing page coded from a Figma design, built with plain HTML, CSS/Sass and the BEM methodology. Content is in Ukrainian.

**Live demo:** [fnazarweb.github.io/modern-backery](https://fnazarweb.github.io/modern-backery)

## About

A single-page bakery website with hero, advantages, traditions, chefs, product formats, and contact sections — including an embedded Google Maps location. Built primarily as practice for HTML/CSS fundamentals, with minimal JavaScript (mobile menu, modal, carousel/slider).

## Tech stack

- **HTML5** — semantic markup
- **Sass/SCSS** — organized into components, layouts, and utils partials
- **BEM methodology** — Block-Element-Modifier naming for all components
- **CSS pseudo-classes/pseudo-elements** — used throughout for styling without extra markup
- **Mobile-first responsive design** — built with `@media` queries and Sass variables for breakpoints
- **Vanilla JavaScript** — mobile menu, modal window, formats slider
- **Prettier** — code formatting
